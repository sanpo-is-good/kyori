# kyori

距離だけを共有するWebアプリ（GitHub Pages版）

公開URL: https://sanpo-is-good.github.io/kyori/

参加者のスマホの位置情報をやり取りし、**お互いの距離だけ**を表示するWebアプリです。地図・方角・座標は画面に出ません。
サーバー不要で、GitHub Pages にファイルを置くだけで動きます。

- ルームを作って招待リンクを送る → 開いた人どうしの距離がリアルタイムで並ぶ
- 「あなたから各参加者まで」の距離（近い順）と「ほかの人どうし」の距離を表示
- 距離は 1m〜100km の対数スケールのバーでも表示

## 公開のしかた（GitHub Pages）

1. このリポジトリを **Public** にしておく
2. Settings → Pages → Build and deployment
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** → Save
3. 1〜2分待つと https://sanpo-is-good.github.io/kyori/ で公開される

あとはそのURLを開いて「新しいルームを作る」→「招待」で友だちにリンクを送るだけです。

## 仕組み

```
スマホA ──暗号化した位置──▶ 公開MQTT中継サーバー ──▶ スマホB, C …
                              （中身は読めない）
各スマホが自分で距離を計算して、距離だけを表示
```

- 中継には誰でも無料で使える公開MQTTサーバーを**2か所同時**に使っています（`broker.emqx.io` と `broker.hivemq.com`）。片方が落ちてももう片方で動きます。
- 位置はルームコードから作った鍵（AES-GCM、PBKDF2で鍵導出）で暗号化してから送ります。鍵は招待リンクの `#` 以降にしか含まれず、`#` 以降はGitHubにも中継サーバーにも送られません。
- どこにも保存しません。中継サーバーには「各自の最新1件（暗号化済み）」だけが一時的に残り、退出や通信切断で消えます。

## 知っておいてほしいこと

- **参加者のスマホには相手の座標が（暗号を解いた状態で）届きます。** 画面には距離しか出しませんが、ブラウザの開発者ツールを使えば見られます。「仲間内で距離だけを楽しむ」ためのアプリです。
- 部外者・中継サーバー・GitHubからは位置は読めません。ただし**招待リンクを知っている人は誰でも参加できる**ので、リンクの共有先には気をつけてください。
- 公開MQTT中継は無料のテスト用サービスで、稼働保証はありません。つながらないときは時間をおいて試してください。中継先は `index.html` 冒頭の `BROKERS` で変えられます。
- 位置を送るのは**画面を開いている間だけ**です。iPhone ではスリープ・別アプリ表示中は止まります（対応ブラウザでは画面が自動で消えないようにしています）。
- 距離にはGPSの誤差が含まれます。距離が誤差より小さいときは「誤差の範囲内」と表示します。

## 表示のルール

- 位置の送信：動いたとき（最短2秒おき）と、動いていなくても10秒おき
- 30秒届かない人は「接続切れ」として薄く表示、3分届かなければ一覧から消える
- 「退出」を押すと、ほかの人の画面から即座に消える

## ファイル構成

```
index.html               画面と処理のすべて
vendor/mqtt.min.js       MQTT通信ライブラリ（MQTT.js 5.16.1, MIT License）
vendor/mqtt-LICENSE.md   そのライセンス
icon.svg                 アイコン
manifest.webmanifest     ホーム画面に追加したとき用
.nojekyll                GitHub Pages の変換を無効にする空ファイル（なくても動きます）
```

## 手元で試す

```bash
python3 -m http.server 8080
# → http://localhost:8080/
```

PCのブラウザなら localhost で位置情報が使えます。スマホで試すときは GitHub Pages に置いたURL（https）で開いてください。
